# Clinic Booking System

A full-stack web application that lets patients browse a clinic's services, meet the practitioners, and book appointments online.

It's designed to be **reusable for any type of clinic** (dental, physiotherapy, GP), with clinic details stored as data rather than hard-coded. The first version is based on a fictional dental clinic.

> ⚠️ This is a portfolio project. The clinic and practitioners are fictional.

## Status
🚧 In progress – Version 1

## Planned features (Version 1)
- Clinic information: address, hours, contact details
- List of services with description, duration, and price
- Practitioner profiles
- Online appointment booking with available time slots
- Admin view of services and bookings

## Tech stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** SQLite

## Roadmap
- **Version 2:** PostgreSQL, Docker, admin login
- **Version 3:** React frontend, practitioner accounts
